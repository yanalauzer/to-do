# To-Do List

Проект приложения для управления задачами.  
Пользователь может добавлять, редактировать, удалять и отмечать задачи как выполненные, а также сортировать, искать и изменять их порядок с помощью drag-and-drop.

## Был реализован следующий функционал:

### Макет страницы
- В HTML-файле оставлен только базовый каркас и подключение JavaScript-файла.  
- Все элементы интерфейса (заголовки, формы, списки и т.д.) создаются через JavaScript с использованием семантических HTML-тегов.  
- Текст, атрибуты и стили применяются через JavaScript с помощью textContent, className и других свойств.  
- Структура страницы формируется динамически методами DOM (append, appendChild и т.д.).  
- Реализована адаптивность с помощью CSS (flex), корректное отображение на разных устройствах.

### Логика приложения
- Реализовано добавление новой задачи с указанием названия, даты и времени.  
- Реализовано удаление задачи из списка.  
- Реализовано редактирование задачи (текст, дата и время).  
- Реализована возможность отмечать задачу как выполненную с изменением визуального оформления.  
- Реализована сортировка задач по дате и времени (сначала ближайшие).  
- Реализована фильтрация задач по статусу (выполнено / невыполнено).  
- Реализован поиск задач по названию.  
- Реализовано сохранение задач в localStorage и восстановление при загрузке страницы.  
- Реализована возможность менять порядок задач с помощью drag-and-drop.
